# Aether UI Bitmap

`font_16.c` and `font_24.c` contain 16 px and 24 px LVGL bitmap glyphs
derived from Lapomme's Huayuan Gothic Regular (`Huayuan.Gothic.Regular.ttf`).
The generated headers retain the LVGL converter settings and input character
list. The upstream release used for the existing bitmaps was not recorded.

The bitmap fonts are distributed under the SIL Open Font License 1.1.
[OFL.Huayuan.txt](OFL.Huayuan.txt) contains the upstream copyright,
Reserved Font Names, and full license text. The derived fonts use the
name Aether UI Bitmap.

Upstream source and font downloads are available from [Lapomme's
Huayuan Gothic repository](https://github.com/lapomme/huayuan).
